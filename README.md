# 一根麵，能撐多重？——峻瑞的力學冒險

從一根義大利麵出發的力學科普漫畫網站。峻瑞和爸爸、媽媽在三堂課裡認識力、材料與形狀，最後遇見歐拉的挫曲公式，並親手完成科展實驗。

作者：王思永 Ed Wang

## 技術

- 純靜態網站：HTML、CSS 加一小段原生 JavaScript，不需要建置步驟
- 圖片從原始 PNG 轉成 JPEG（品質 85），並標註寬高，避免捲動時版面跳動
- 每頁都有錨點，可以直接分享某一頁，例如 `#p21`
- 支援手機版與深色模式
- 以 GitHub Pages 發布（main 分支，根目錄）

## 檔案結構

index.html   頁面
style.css    樣式
script.js    章節選單、閱讀進度條、回到頂端
